# 🔷 Albatastic Meshtastic Nodes

## 🇪🇸 Descripción

Este repositorio recopila la familia de nodos **Albatastic**, diseñados para ser compatibles con Meshtastic. Todos los diseños están basados en el MCU **nRF52840** y soportan configuraciones LoRa de **1W**, ofreciendo un equilibrio entre rendimiento, alcance y eficiencia energética.

El objetivo de este repositorio es centralizar la documentación, enlaces y referencias de los distintos proyectos Albatastic para facilitar su consulta, comparación y construcción.

### 📡 Incluye:
- Albatastic PRO  
- Albatastic Node  
- Albapipe Meshtastic Node  

---

## 🇬🇧 Description

This repository collects the **Albatastic family** of Meshtastic-compatible nodes. All designs are based on the **nRF52840 MCU** and support **1W LoRa configurations**, providing a balance between performance, range, and power efficiency.

The purpose of this repository is to centralize documentation, links, and references for the different Albatastic projects to make them easier to browse, compare, and build.

### 📡 Includes:
- Albatastic PRO  
- Albatastic Node  
- Albapipe Meshtastic Node
